# 模块四：关卡推进、探索循环与资源经济系统 (Game Loop, Economy & Progression)

## 1. 核心游戏循环图谱 (The Grand Game Loop)

整个游戏的体验闭环建立在 **“战斗验证 $\to$ 战利品捕获 $\to$ 基地培育突变 $\to$ 构筑质变 $\to$ 突破高阶关卡”** 的正向反馈齿轮上。

```
              ┌──────────────────────────────────────┐
              │          1. 关卡探索与地下城挑战      │
              │  - 推进剧情地图 / 爬塔深渊 / 狩猎首领  │
              └──────────────────┬───────────────────┘
                                 │
                     战胜掉落    ▼    遭遇稀有怪
              ┌──────────────────────────────────────┐
              │          2. 战利品与基因资源获取     │
              │  - 捕获野生胚胎 / 掉落宠物原石        │
              │  - 掉落技能秘笈、基因稳定剂、金币     │
              └──────────────────┬───────────────────┘
                                 │
                     返回基地    ▼    投入资源
              ┌──────────────────────────────────────┐
              │          3. 基因研究所深度培育       │
              │  - 查配方表：低阶升阶合成 (T1 -> T2)  │
              │  - 锁定神技、筛选词条、触发良性突变   │
              │  - 学习机打书完善技能槽              │
              └──────────────────┬───────────────────┘
                                 │
                     战力飞跃    ▼    调整战术
              ┌──────────────────────────────────────┐
              │          4. 角色职业流派协同加点     │
              │  - 根据新合出的主力宠切换职业战术    │
              │  - 洗点匹配指挥乘区 (暴发/反伤/元素)  │
              └──────────────────┬───────────────────┘
                                 │
                     战力质变    ▼    挑战极限
                               回到 1 (挑战更高难度)
```

## 2. 宠物获取机制设计：双轨制（野外投掷捕获 + 胚胎孵化）

为了保持收集的成就感，采用两种获取途径：

### 2.1 战斗中投掷【灵能捕捉网】(In-Battle Capture)
- 在战斗中，当敌方野生生物生命值降至 $30\%$ 以下或处于异常状态（冰冻/眩晕）时，角色的道具栏可使用【灵能捕捉网】；
- 捕捉成功率：
  $$\text{捕捉概率} = \text{基础捕获率} \times \left(1 - \frac{\text{当前血量}}{\text{最大血量}}\right) \times \text{道具品质系数}$$
- 成功捕获后，战斗立即结算该生物，直接进入玩家的宠物仓库。

### 2.2 关卡结算掉落【封印胚胎 / 宠物蛋】(Egg Hatching)
- 首领关卡与深渊宝箱会掉落不同属性的【宠物原石蛋】（如：熔岩蛋、深海蛋、神秘变异蛋）；
- 玩家带回基地后在【孵化舱】消耗少量金币直接破壳，随机生成特定种族的 T1 或 T2 初始宠物，作为基因融合的丰沛“原材料”。

## 3. 游戏资源经济学模型 (Economy Loops & Sinks)

一套健康的养成经济系统必须做到：**产出有期待，消耗有深度，杜绝不可逆贬值**。

| 资源名称 | 获取途径 (Sources) | 核心消耗场景 (Sinks) | 经济调控作用 |
| :--- | :--- | :--- | :--- |
| **金币 (Gold)** | 副本通关、出售多余材料、任务成就 | 基因合成手续费、宠物升级、购买普通技能书 | 基础流动通货，平缓消耗，防止前期溢出 |
| **基因稳定剂 (Memory Crystal)** | 挑战精英怪、周常深渊、分解高阶宠物 | **合成时锁定 1 个指定技能 100% 遗传** | 顶级策略资源，为玩家追求“完美毕业宠”提供确定性保底 |
| **技能秘笈 (Skill Books)** | 隐藏宝箱、首领掉落、商店限购 | 宠物打书学习新技能、替换次级技能 | 拓展宠物的策略维度，支持多样化流派定制 |
| **基因回炉精粹 (Pure Essence)** | 不满意的合成结果选择“回炉分解” | 在基因商店直接兑换自选的高级技能书 | **核心防挫败保障**：让每一次“赌失败”都能积累硬通货 |

## 4. 关卡难度阶梯与推进节奏 (Difficulty Pacing)

关卡分为 **四大篇章**，严格对应玩家的前后期心流转换：

1. **第一篇章：【边境荒野】(Lv.1 ~ Lv.12)**
   - *关卡特点*：敌人血量低（100~300）、双抗极低。
   - *设计目的*：让玩家尽情体验角色单挑横扫的快感。教程引导玩家抓获第一只野狗/火蜥蜴。
2. **第二篇章：【古代遗迹】(Lv.13 ~ Lv.25)**
   - *关卡特点*：出现高物防敌人（需要元素攻击破盾）、敌人具备群体控制。
   - *设计目的*：角色的单兵输出开始受到防御压制，系统引导玩家使用【基因研究所】将两只 T1 宠物合成出首只 T2 稀有宠。角色学会给宠物加攻击，体验初现。
3. **第三篇章：【元素熔炉与苍穹裂隙】(Lv.26 ~ Lv.40)**
   - *关卡特点*：敌人具备免死盾、高爆发狂暴机制。
   - *设计目的*：纯靠角色已完全无法通关。玩家必须通过 4 大职业的天赋树洗点（如重装教官反伤或狂暴学者超载），培育出多词条极品 T3 史诗宠物，通过角色战术指挥通关。
4. **第四篇章：【深渊回廊（无尽挑战）】(Lv.41+)**
   - *关卡特点*：词缀轮换（如暴击抗性+80%、全屏每回合Dot掉血）。
   - *设计目的*：高难 Endgame 玩法，考验玩家培育多套不同流派的特化毕业宠并灵活切换角色职业。
