# 模块一：战斗系统与前后期输出动态迁移机制 (Combat & Dynamic DPS Transition Engine)

## 1. 设计初衷与核心痛点思考 (Core Problems to Solve)

在“开局靠角色、后期靠宠物”的体验诉求中，传统数值设计极易出现两大致命痛点：
1. **“断崖期”困境（真空期卡关）**：角色输出在某个等级突然打不动怪，而此时玩家的高阶宠物还没合成出来，导致战斗体验骤降。
2. **“工具人失落感”**：如果后期角色完全变成无存在感的纯挂件，玩家会失去对主角的角色认同。

本模块的核心任务是：**通过平滑的数学公式曲线、行动条调度机制与“软着陆”设计，实现角色从“冲锋打手”到“战术大脑”的爽快质变**。

---

## 2. 回合调度与行动时序机制 (Action Gauge / CTB System)

采用类似《最终幻想X》与《崩坏：星穹铁道》的 **动态行动值序列系统 (Conditional Turn-Based / CTB)**，而非死板的轮流出手，以便支撑“速度流宠物”、“战术再动”等高阶玩法。

### 2.1 行动值计算公式
每个单位在时间轴上的距离称为 **剩余行动距离 (Distance)**，初始为 10,000 点：

$$\text{行动消耗时间 (Ticks)} = \frac{\text{当前剩余行动距离}}{\text{单位当前速度 (SPD)}}$$

- 每次时钟推进，时间流逝量为当前序列中最快单位行动所需的时间；
- 该单位行动后，其剩余距离重置为 $10,000$ 并根据技能后摇/加速状态衰减；
- **战术再动 (Action Surge)**：直接将指定单位的剩余行动距离置为 $0$，强制插队立即行动。

### 2.2 小队阵型与仇恨分配
- **阵型规则**：固定 $1$ 角色 + 最多 $3$ 只宠物，分为【前排】与【后排】。
- **基础仇恨权重 (Aggro)**：
  - 前排单位：基础受击概率 $40\%$；
  - 后排单位：基础受击概率 $15\%$；
  - 角色使用【嘲讽/防御态姿】时：受击概率提升至 $90\%$，为后排脆皮核心宠物创造输出空间。

## 3. 前后期输出迁移数学模型 (Mathematical Progression Model)

### 3.1 伤害基础公式与乘区拆解
所有伤害均按以下统一的乘区流水线结算：

$$\text{最终伤害} = \text{基础区} \times \text{技能倍率区} \times \text{增伤减伤区} \times \text{防御减免区} \times \text{暴击区} \times \text{元素克制区} \times \text{指挥放大区}$$

#### (1) 基础区 (Base Pool)
- **角色攻击**：$\text{基础值} = \text{角色基础固定伤害}(A_c) + \text{角色攻击力}(ATK_c) \times k_c$
- **宠物攻击**：$\text{基础值} = \text{宠物攻击力}(ATK_p) \times k_p$

#### (2) 防御减免区 (Defense Mitigation)
怪物受到攻击时的减免公式采用非线性收益曲线：

$$\text{防御减免系数} = \frac{1000}{1000 + \text{目标防御力} \times (1 - \text{破防率})}$$

### 3.2 数值曲线如何“逼迫”重心转移（且不产生断崖）

```
输出
贡献度
100% ┤ 角色输出 (开局占90%) ╲                / 宠物输出 (后期占90%)
     │                        ╲            /
 50% ┤                          ╲─ 中期 ─/
     │                            (5:5)
  0% └───────────────────────────────────────────────►
      Lv.1 ~ 15 (开荒期)     Lv.16 ~ 30 (蜕变期)   Lv.31+ (核爆期)
```

1. **前期（Lv.1 ~ 15，角色是神）**：
   - 角色技能设计：高 $A_c$ 固定数值（如 Lv.1 战技固定附加 $150$ 点伤害），而此时关卡怪血量只有 $80 \sim 200$。
   - 结果：角色手起刀落一刀秒杀；而此时抓到的 T1 幼宠基础攻击仅为 $15$，打怪只有个位数伤害。
2. **中期（Lv.16 ~ 30，平滑软着陆期）**：
   - 怪物的防御力上升到 $300 \sim 600$，血量达到 $2000 \sim 5000$。
   - 角色的固定加成 $A_c$ 收益边际递减；此时角色若纯打物理输出，只能打掉怪 $25\%$ 血量。
   - 此时玩家合成出首只 T2 宠物（自带破甲、连击），角色开始使用技能附加【流血/碎甲】等辅助效果，角色打一半、宠物打一半，体验平稳过渡。
3. **后期（Lv.31+，宠物核爆）**：
   - 怪物的血量高达 $50,000 \sim 500,000$，且具备特定减伤盾。
   - 宠物的攻击力随着多代培育和资质提纯突破上千，且多重被动词条（暴击伤害 $+150\%$、追击、属性克制）生效。
   - 此时角色技能不再追求打出自身伤害，而是提供特殊的【指挥乘区】：
     $$\text{指挥放大区} = (1 + \text{指挥增伤}) \times \text{必爆补正}$$
   - 角色一个指令让宠物伤害翻 $3 \sim 5$ 倍，宠物打出几十万一击，秒杀 BOSS。

## 4. 战斗有限状态机详细流程 (Battle FSM)

```
[BATTLE_INIT] (初始化队伍、加载配置、重置行动序列)
      │
      ▼
[TURN_DECIDE] (时钟推进，抓取行动距离最短的单位作为当前出手者)
      │
   ┌──┴──────────────────────────────────────┐
   ▼                                         ▼
[PLAYER_INPUT] (若出手者为我方单位)         [AI_DECIDE] (若出手者为敌方单位)
- 角色行动：攻击 / 技能 / 战术指挥指令       - 根据行为树选择技能与目标
- 宠物行动：普攻 / 释放技能 (可由AI/玩家控制)
   └──┬──────────────────────────────────────┘
      ▼
[ACTION_RESOLVE] (结算伤害、计算乘区、触发被动、判定连携/追击)
      │
      ▼
[BUFF_TICK & CLEANUP] (状态回合结算、Buff消退、死者离场)
      │
      ├──> [CHECK_VICTORY] ──(全歼敌人)──> [BATTLE_WIN] -> 结算掉落
      ├──> [CHECK_DEFEAT]  ──(全队阵亡)──> [BATTLE_LOSE] -> 失败重整
      └──> [NEXT_TURN]     ───────────────> 返回 [TURN_DECIDE]
```

## 5. 战斗异常与极端边缘处理 (Edge Cases & Safety)

1. **角色阵亡而宠物存活**：
   - 角色阵亡后，战斗不立即失败；角色进入“昏迷”状态，此时失去角色指挥技能；宠物失去指挥增益，依靠自身基础 AI 继续战斗，强化玩家“保护主角”或“宠物的独立战斗韧性”。
2. **宠物全灭而角色存活**：
   - 前期角色完全可以单挑翻盘；但若在后期发生此情况，角色输出极低，系统允许角色施放一次性的紧急撤退指令【战略遁走】，保全当前战利品。
3. **死循环追击防护**：
   - 追击/连动技能（如巡林客被动）严格限制 **“单次回合内追击链最大触发次数 $\le 3$ 次”**，防止特定词条组合造成无限死循环。
