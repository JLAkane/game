# 宠物养成回合制策略RPG设计规范文档 (Design Specification)

## 1. 项目愿景与设计理念 (Game Vision)

- **核心主题**：以宠物深度培育与基因为核心驱动力的回合制策略 RPG。
- **动态输出权重迁移 (Dynamic DPS Transition Curve)**：
  - **前期 (Early Game)**：角色自身是主力单兵打手，依靠强力战技一击杀怪，宠物作为幼体挂件提供微量辅助/承伤。
  - **中期 (Mid Game)**：宠物初次合成升阶，角色开始学习协同破甲与增益技能，角色与宠物伤害五五开。
  - **后期 (Late Game)**：极品多词条/高阶巨兽宠物成型，角色彻底洗点/转型为战术指挥枢纽（提供易伤标记、暴击超载、战术再动），全队 90%+ 输出由宠物打出。
- **解耦设计准则**：
  - **培育系统独立客观**：所有玩家面对完全相同的合成配方表、概率与打书规则，不因角色职业产生培育特权或门槛。
  - **职业驱动流派构建 (Build-Driven)**：角色的职业技能树决定了战斗协同机制，从而自然牵引玩家去定向培育契合的宠物流派（单体核爆、防守反击、元素连锁、追击连动）。

## 2. 战斗与队伍系统架构 (Combat & Team System)

### 2.1 编队编制
- **小队规格**：固定 **1 名主角 + 最多 3 只出战宠物**，与敌方小队在同一战斗界面展开对抗。
- **站位布局**：
  - 前排：通常配置高体质/护卫型宠物或肉装角色。
  - 后排：主力输出宠物或法系/辅助单位。
- **回合调度逻辑**：
  - 基于单位 **速度 (Speed)** 属性的行动序列轴（Action Gauge），速度高的单位优先获得回合。
  - 战斗资源：每个单位拥有自身生命值 (HP) 与魔法/战技点 (MP/TP)。角色拥有特殊的指挥指令槽。

### 2.2 伤害计算公式
为了实现“前期角色强、后期宠物核爆”的平滑过渡，采用加乘分立模型：

$$\text{角色技能伤害} = (\text{基础固定威力} + \text{角色攻击} \times \alpha) \times (1 + \text{增伤系数})$$

- 角色自身攻击技能的 $\text{基础固定威力}$ 在前期很高（保证无视装备秒怪），但 $\alpha$ 成长系数平缓，无后期乘区放大。

$$\text{宠物最终伤害} = (\text{宠物攻击} \times \beta) \times (1 + \text{种族克制}) \times (1 + \text{词条倍率}) \times (1 + \text{角色指挥放大倍率}) \times \text{暴击倍率}$$

- 宠物基础攻击随阶级和代数呈指数级成长，且角色的指挥技能提供巨额的 $(1 + \text{角色指挥放大倍率})$（如 $+200\%$ 伤害、必定暴击），最终实现后期的毁天灭地。

## 3. 独立宠物培育与基因合成系统 (Pet Breeding & Fusion)

培育系统是一个纯数据驱动的客观子系统，涵盖配方表合成、技能遗传、词条打书三大支柱。

### 3.1 宠物基本数据结构
每个宠物由以下核心维度构成：
1. **物种基础配置 (Species Config)**：物种ID、名字、初始品阶（T1普通、T2稀有、T3史诗、T4传说）、种族（兽系/龙系/亡灵/元素/机械）、固有专属技。
2. **六维属性与成长资质**：
   - 生命 (HP)、攻击 (ATK)、防御 (DEF)、速度 (SPD)、暴击率 (CRIT)、暴击伤害 (CRIT_DMG)。
   - 成长资质：决定升级时属性的增加幅度。合成时继承自父母双方的均值并附带小幅浮动。
3. **技能栏位 (Skill Slots)**：
   - 包含 1 个固有专属技 + 最多 4 个继承/后天打书技能。

### 3.2 基因融合配方表体系 (Dual-Track Recipe System)

#### (1) 特殊指定配方表 (`recipes_special.json`)
明确规定两只特定宠物合成能够跃迁产出更高阶的稀有物种：
```json
[
  {
    "parentA": "fire_lizard",
    "parentB": "rock_turtle",
    "child": "magma_behemoth",
    "tier": 2,
    "desc": "火蜥蜴 + 岩壳龟 = 熔岩巨兽"
  },
  {
    "parentA": "magma_behemoth",
    "parentB": "storm_falcon",
    "child": "hellfire_dragon",
    "tier": 3,
    "desc": "熔岩巨兽 + 暴风隼 = 狱火炎龙"
  },
  {
    "parentA": "spectral_wisp",
    "parentB": "bone_hound",
    "child": "death_knight",
    "tier": 2,
    "desc": "幽魂 + 骸骨犬 = 死亡骑士"
  }
]
```

#### (2) 通用种族/阶级配方表 (`recipes_generic.json`)
未命中指定配方时的通用合成逻辑：
- **品阶判定 (Tier Upgrade)**：
  - $\text{Tier 1} + \text{Tier 1} \to 80\%$ 概率升为 $\text{Tier 2}$，另有 $20\%$ 保底为高资质 $\text{Tier 1}$。
  - $\text{Tier 2} + \text{Tier 2} \to 70\%$ 概率升为 $\text{Tier 3}$。
  - 跨阶合成（如 $\text{Tier 2} + \text{Tier 1}$）品阶锁定为高阶方（用于提纯技能与资质）。
- **种族判定 (Family Matrix)**：
  - 查表决定子系种族，如：$\text{兽系} + \text{龙系} = \text{龙系}$，$\text{水系} + \text{火系} = \text{元素系}$。

### 3.3 技能与词条继承机制 (Skill Inheritance)
1. **技能候选池**：汇总父方与母方所有非固有技能，去重后生成。
2. **继承概率**：
   - 普通被动/主动技：$60\%$ 继承率。
   - 高级/金色稀有技：$35\%$ 继承率。
   - 保底：子代至少成功继承 1 个技能（若全落空则随机强行命中 1 个）。
3. **基因稳定剂 (Gene Stabilizer)**：
   - 消耗游戏内资源（记忆水晶），可在合成前**勾选锁定 1 个指定神技 100% 遗传**给子代。
4. **良性突变 (Mutation Chance)**：
   - 每次合成有 $5\%$ 概率发生基因突变，额外获得一条未在父母技能池中的稀有特性（如【狂怒追击】、【残血不屈】）。

### 3.4 技能打书系统 (Skill Books)
- 探索与关卡掉落【技能秘笈】。
- 若技能栏有空格直接习得；若已满，可选择指定槽位替换，确保后期 Build 可微调打磨。

## 4. 角色多职业与宠物协同体系 (Character Classes & Synergy)

角色拥有 4 大职业，前期自带强力物理/法术直伤战技；后期通过技能树蜕变为对应流派的宠物战术核心。

### 4.1 职业一：【战术指挥官 / 狂暴学者】$\to$ 适配【单体极值爆发流宠物】
- **前期个人输出**：【斩击】、【重装轰炮】，高倍率单体秒怪。
- **后期指挥机制**：
  - 【弱点指示】：使目标受到来自宠物的单体暴击伤害提升 $150\%$。
  - 【超载注射】：使主力宠物本回合攻击翻倍、必定暴击、扣除 10% 生命。
  - 【战术再动】：牺牲自身行动，让指定宠物本回合再次行动一次。
- **驱动培育目标**：极限堆满攻击力资质、全打单体爆伤技能的“一拳超人型”宠物。

### 4.2 职业二：【重装铁壁领主】$\to$ 适配【防守反击/荆棘刺猬流宠物】
- **前期个人输出**：【旋风斩】、【重盾猛击】，高生存高容错。
- **后期指挥机制**：
  - 【挑衅嘲讽】：吸引全屏敌人攻击角色，自身开启 $70\%$ 减伤。
  - 【防反号令】：为全体宠物赋予【荆棘共鸣】，宠物受到攻击时反弹 $300\%$ 伤害并累计怒气值。
  - 【怒火释放】：将全队受到的累计伤害转化为宠物下一次范围反击伤害。
- **驱动培育目标**：极限血量与双抗资质、打满反伤、吸血、受击充能技能的高防巨兽。

### 4.3 职业三：【灵能元素使】$\to$ 适配【跨系连锁/元素全屏核爆流宠物】
- **前期个人输出**：【炽热火球】、【引力闪电】，基础伤害极高的远程法术。
- **后期指挥机制**：
  - 【元素引力场】：聚集敌人并降低全场元素抗性 $40\%$。
  - 【法力谐振】：宠物的法术技能命中后触发连锁传导，伤害在敌方单位间弹跳 3 次。
  - 【奥术充能】：直接为全队宠物回复满 MP，使其能够连续开大。
- **驱动培育目标**：高魔攻法系宠，分别打上火、雷、风等大范围 AOE 技能，触发元素连锁反应。

### 4.4 职业四：【敏捷巡林客】$\to$ 适配【多动连斩/暴风追击流宠物】
- **前期个人输出**：【穿心狙击】、【多重连射】，高敏捷高暴击。
- **后期指挥机制**：
  - 【追猎标记】：射出弱化印记箭，友方宠物对其造成伤害时 $100\%$ 概率追加一次普通攻击。
  - 【群狼呼啸】：全队宠物行动速度增加 $50\%$，暴击后获得 $30\%$ 概率额外再行动。
- **驱动培育目标**：极速刺客型宠物、打满连击、追击、暴击率词条。

## 5. 技术架构与工程实现规范 (Technical Architecture)

### 5.1 架构分层
1. **Core Logic Engine (纯 TypeScript 无状态/状态机，易于独立单元测试)**：
   - `BattleEngine`：状态机管理（`ROUND_START` -> `TURN_DECISION` -> `ACTION_RESOLVE` -> `ROUND_END`）。
   - `DamageCalculator`：纯函数公式计算，支持各类 Buff/Debuff 与乘区。
   - `BreedingEngine`：配方表匹配器、技能遗传随机发生器、资质混合器。
2. **Data Model Layer**：
   - 配置表加载器与强类型定义（`PetDef`, `RecipeDef`, `SkillDef`, `ClassDef`）。
   - 本地存档管理器（`SaveManager`，基于 `localStorage`，支持导出导入 JSON）。
3. **Presentation Layer (Web 前端)**：
   - 构建工具：`Vite` + `TypeScript`。
   - 战斗场景：HTML5 Canvas / Pixi.js 渲染（包含精灵站位、血条、飘字与攻击特效）。
   - 界面系统：现代响应式 UI（宠物背包、基因合成台、角色技能树加点盘）。

## 6. 研发实施路线图 (Implementation Milestones)

- **Phase 1: 核心战斗原型与输出转移验证 (MVP)**
  - 搭建 Vite + TS 基础工程。
  - 实现回合制战斗循环与行动序列计算。
  - 录入测试数据（角色自身伤害技能 vs 角色指挥技能 + 宠物高伤技能），验证从前期单人打到后期依靠宠物的数值手感。
- **Phase 2: 宠物培育与基因合成引擎**
  - 实现配方表读取（特殊配方 + 通用升阶）。
  - 实现遗传概率、技能锁和良性突变算法。
  - 完成基因合成台 UI 与图鉴展示。
- **Phase 3: 角色多职业与指挥技能树**
  - 实现 4 大职业的数据与技能树分支。
  - 完善角色指挥技能对宠物的战场增幅（再动、超载、荆棘、追击）。
- **Phase 4: 关卡推进、掉落与打磨**
  - 关卡地图推进与刷怪掉落（胚胎、技能书、材料）。
  - 技能打书与替换交互。
  - 本地存档、音效与视觉反馈打磨。
