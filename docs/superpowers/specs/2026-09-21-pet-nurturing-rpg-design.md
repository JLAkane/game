# 宠物养成回合制策略RPG：系统设计主索引规范 (Master Specification)

> **设计核心理念**：以宠物深度培育与基因融合为核心驱动力，开局主要依赖角色自身战技高额输出，中后期依靠角色职业指挥增幅与宠物协同，彻底转变为以宠物作为绝对输出大核的回合制策略 RPG。

---

## 研发落地路线图 (Implementation Milestones)

- **Phase 1: 核心战斗原型与输出转移验证 (MVP)**
  - 搭建 Vite + TS 纯逻辑与测试环境；
  - 跑通回合制战斗循环，录入角色初期直伤 vs 宠物后期被动+角色指挥，验证输出权重的无缝质变手感。
- **Phase 2: 宠物培育与基因合成引擎**
  - 实现配方解析器（特殊指定公式 + 通用阶级升阶计算）；
  - 落地技能遗传、基因稳定剂锁定与突变系统；
  - 构建基因合成台 UI 与图鉴查询。
- **Phase 3: 角色多职业与战术指挥技能树**
  - 实现 4 大职业的切换与技能树逻辑；
  - 实现战术再动、超载注射、荆棘反震、追猎引导等核心机制。
- **Phase 4: 关卡探索循环与系统打磨**
  - 关卡地图推进、野外投掷捕获与胚胎孵化；
  - 学习机技能打书；
  - 存档持久化、界面动画与视听体验调优。
